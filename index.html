Ado Operating System

An Alpine Linux 3.24.1 derivative. Unmodified musl libc, OpenRC, and standard apk packages. AdoOS adds a deterministic build system and a minimalist developer overlay.

Base System (•_•)

Unmodified Alpine Base

Alpine 3.24.1 with musl libc and OpenRC. The aports tree is an untouched upstream checkout, eliminating libc fragmentation.

Pure Alpine Compatibility
Package Flow (⊙_⊙)

Native apk Integration

The package manager is Alpine's apk: same repository ecosystem and security model. AdoOS customizations are contained in profile overlays.

No Custom Fork Overhead
Determinism d(ﾟ-ﾟ*)

Reproducible Builds

Kernel pinned to Alpine's linux-lts 6.18.39. The image timestamp matches the git commit to ensure byte-for-byte reproducibility.
