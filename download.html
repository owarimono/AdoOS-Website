Compile the AdoOS ISO

AdoOS is distributed as source recipes. The ISO is produced directly by Alpine’s native mkimage.sh inside a rootless user namespace.

Source Tree Status v0.1.0 dev Pure Musl libc • OpenRC
Quick Build Command
(•̀ᴗ•́)و

Run this single command on any modern Linux host. It downloads an isolated Alpine rootfs and compiles the ISO without needing sudo or root privileges:

scripts/build-iso.sh
# Resulting artifacts written to ./iso
iso/adoos-3.24.1-x86_64.iso
iso/adoos-3.24.1-x86_64.iso.sha256
